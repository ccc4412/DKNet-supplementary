## Headline findings

1. **5-seed mean±std (BERT as-of/streaming, refresh=1500)**  
   - HASHET-zh P@10 = 0.0070 ± 0.0005  
   - H-ADAPTS-zh P@10 = 0.0084 ± 0.0003  
   (see `S3_multiseed_summary.json` / paper Table proxy_real)

2. **Row-level bootstrap (seed 42)**  
   - HASHET P@10 CI ≈ [0.0057, 0.0072]  
   - H-ADAPTS P@10 CI ≈ [0.0076, 0.0093]  
   - CIs do not overlap strongly with each other on this seed; paired test below is the primary claim.

3. **HASHET vs H-ADAPTS (paired, seed 42, n=4637 shared rows)**  
   - Mean ΔP@10 (HASHET − H-ADAPTS) ≈ **−0.0017**, bootstrap CI excludes 0  
   - Wilcoxon signed-rank p ≈ **1e-6** (H-ADAPTS higher on sparse weak labels)

4. **DKNet KG ablation (ctx=300, n_paired=56 labeled rows)**  
   - Mean ΔP@10 (full − no-KG) ≈ **+0.0187**, bootstrap CI excludes 0  
   - Wilcoxon: all non-zero pairs favor full (w_minus=0); **p &lt; 1e-6**  
   - Removing KG eliminates essentially all hits (no-KG means are 0)

5. **DKNet MMR (ctx=300)**  
   - Full vs no-MMR is near-zero / neutral under sparse weak labels (consistent with paper text).

## Notes for reviewers

- Absolute proxy P@10 (~0.01) is **not** comparable to the synthetic main table (~0.7); labels are sparse (~15% of rows, mean 1.31 tags/row).  
- Non-parametric tests complement the main-table paired *t*-tests (R1 statistical transparency).  
- HASHET/H-ADAPTS use the same candidate pool, top-K=10, and weak-label stripping as DKNet proxy.
