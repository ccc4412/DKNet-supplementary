## 1. 协议对齐说明（可比性基础）

三方在**同一数据、同一弱标注协议、同一指标公式**下对比:

- **指标**: P@10（分母固定 10）/ R@10 / F1@10 / hit@10，仅在含标签行上平均
  ——与 DKNet checkpoint summary 与 weak_eval 的公式逐位一致
  （本报告评测器已复算 DKNet 全部 jsonl, 与其官方汇总数字完全吻合, 见 §2）。
- **DKNet proxy 运行**: 上下文流式协议——预测第 i 行时以全部前 i-1 行文本为
  LLM 上下文; `state_seed_N` 系列的 N 是**上下文行数（seeded rows）而非随机种子**。
- **HASHET-zh（本报告新跑）**: as-of 协议——每 300 行用此前全部弱标注行重训
  W2V+MLP（官方两阶段日程, bert-base-chinese）, 预测当前段弱标注行。
- **H-ADAPTS-zh（本报告新跑）**: 滚动窗口流式——tumbling window=300 行
  （伪时间映射, 偏离声明 D10）, K=10, τ=0.9（官方原值）, 切换触发渐进微调。
- 冷启动行为可比: 两种 baseline 在"无标注历史"时与 DKNet"无上下文"时同为 0。

## 4. 与论文主张的对比分析

### 4.1 三个评测层级不可跨层比数字

| 层级 | 语料 | 标注 | P@10 量级 |
|---|---|---|---|
| 论文主表（Table main_results） | 合成 D1（15 万帖, 5.2 关键词/帖, 稠密标注） | 全量实体/相关性标注 | 0.65–0.83 |
| 论文半真实检验（Table semi_real_check） | 真实事件名 + 合成表面 | 探针标注 | 0.70–0.78 |
| **本报告（真实 microblogPCU 弱标注）** | 真实微博 | hashtag 弱标签, 15.3% 行, 1.31/行 | **0.007–0.023** |

绝对数值不可比：标注密度、标签空间、噪声结构完全不同。proxy 数字回答的是
"方法在真实稀疏弱监督下是否保持相对优势"，不是主表数字的复刻。

### 4.2 真实数据揭示的四个事实（修订论文时应吸收）

1. **冷启动主导性能**：DKNet 在 ctx≤30 时为 0.000，ctx≥200 才进入 0.016+；
   我们的监督 baseline 在无标注历史时同样为 0。真实流场景下"历史积累量"
   是第一阶变量——论文的 TtC/自适应叙事应补充这一维度。
2. **KG 组件是命中主要来源**（no_kg=0.000, bootstrap p≈2.8e-17）：与论文
   "结构信号贡献"的主张一致, 且在真实数据上更强。
3. **MMR 在稀疏弱标注下轻微负向**（no_mmr 0.0193 > full 0.0187; weak_eval 同向
   0.0128 vs 0.0130）：与论文合成主表"MMR 贡献覆盖率增益"方向相反。
   修订建议: 在论文中把 MMR 的收益条件限定为"标签较稠密/候选冗余较高"的场景,
   并引用本 proxy 结果作为佐证（避免 Reviewer 质疑选择性呈现）。
4. **自适应机制在短流真实数据上未激活**（no_adaptive == full @300 行;
   adaptive_hybrid_mmr == hybrid_mmr @4,834 行）: 论文的漂移触发式自适应
   需要足够长的流才会体现。建议在 Limitations 补充此观察。
