# Deposit notes — D1/D2 generator, DKNet implementation, and proxy runners

This note describes the code artifacts deposited in this repository for the PLOS ONE
revision of PONE-D-26-27804, as requested by Reviewer #1.

The deposit intentionally ships **code only**. The five-seed per-run observations behind
the manuscript's main table are not part of this package; they are regenerated by
`experiments/run_experiments.py` (see below) and are available from the corresponding
author on request.

## Contents

| Path | What it is |
|---|---|
| `data/generate_datasets.py` | D1 (Weibo-style) and D2 (news-style) synthetic corpora generator. Defaults: 150,000 / 50,000 records, seed 42. Also contains `apply_concept_drift_d1`. |
| `src/` | DKNet implementation: temporal KG, LLM candidate generation, adaptive fusion, MMR, contrastive learning, model, metrics, baseline wrappers, data processing. |
| `experiments/` | Experiment runner and plotting scripts. |
| `config.yaml`, `requirements.txt` | Runner hyper-parameters and dependencies. |
| `scripts/` | MicroBlogPCU proxy runners (context/checkpoint ablations) that produced the numbers in `supporting_information/`. |

## Regenerating the corpora

```bash
python data/generate_datasets.py \
    --output_dir data/datasets \
    --d1_samples 150000 --d2_samples 50000 --seed 42
```

The generator is deterministic for a fixed seed. The full corpora are regenerated with
this command; they are not stored in git because of size.

## Reproducing the five-seed main results

```bash
pip install -r requirements.txt
python experiments/run_experiments.py --config config.yaml --datasets D1 D2
```

`run_experiments.py` writes `dknet_<corpus>_detailed.json`, `baseline_<corpus>_results.json`
and a comparison table per corpus. The per-seed values behind the manuscript's main table
are produced by this command and are available from the corresponding author on request.

## Notes for reviewers

- Absolute P@10 values are not comparable between the synthetic corpora (~0.65–0.83) and
  the MicroBlogPCU weak-label proxy (~0.01); see the manuscript's evaluation-layer section.
- The proxy materials (31,530 posts, 4,834 weak-labelled rows) and all ablation statistics
  are already public under `supporting_information/`; `scripts/` only adds the runners
  that produced them.
