# DKNet repository addendum — D1/D2 generator, DKNet implementation, and proxy runners

This folder stages the code artifacts that Reviewer #1 asked to see in the public
repository (`https://github.com/ccc4412/DKNet-supplementary`). Nothing here has been
uploaded yet; the folder mirrors the paths the repository expects, so it can be copied in
as-is.

This addendum intentionally ships **code only**. The five-seed per-run observations behind
the manuscript's main table are not part of this package; they are generated by
`experiments/run_experiments.py` (see below) and are available from the corresponding
author on request.

## Contents and target paths in the public repository

| This folder | Target path in `DKNet-supplementary` | What it is |
|---|---|---|
| `data/generate_datasets.py` | `data/generate_datasets.py` | D1 (Weibo-style) and D2 (news-style) synthetic corpora generator. Defaults: 150,000 / 50,000 records, seed 42. Also contains `apply_concept_drift_d1`. |
| `data/datasets_sample/` | **do not upload as the corpus** | 100-record D1 / 80-record D2 smoke sets plus `dataset_statistics.json` (seed 42). Kept only so the adapter and baselines can be smoke-tested without regenerating. |
| `src/` | `src/` | DKNet implementation: temporal KG, LLM candidate generation, adaptive fusion, MMR, contrastive learning, model, metrics, baseline wrappers, data processing. |
| `experiments/` | `experiments/` | Experiment runner and plotting scripts. |
| `config.yaml`, `requirements.txt` | repository root | Hyper-parameters and dependencies for the runner. |
| `proxy_scripts/` | `scripts/` | MicroBlogPCU proxy runners (context/checkpoint ablations) that produced the numbers already in `supporting_information/`. |

## Regenerating the corpora

```bash
python data/generate_datasets.py \
    --output_dir data/datasets \
    --d1_samples 150000 --d2_samples 50000 --seed 42
```

The generator is deterministic for a fixed seed; `data/datasets_sample/dataset_statistics.json`
records the seed and the record counts of the shipped smoke sets.

## Reproducing the five-seed main results

```bash
pip install -r requirements.txt
python experiments/run_experiments.py --config config.yaml --datasets D1 D2
```

`run_experiments.py` writes `dknet_<corpus>_detailed.json`, `baseline_<corpus>_results.json`
and a comparison table per corpus. The per-seed values behind the manuscript's main table
are not shipped in this addendum; they are produced by this command and are available from
the corresponding author on request.

## Notes for reviewers

- Absolute P@10 values are not comparable between the synthetic corpora (~0.65–0.83) and
  the MicroBlogPCU weak-label proxy (~0.01); see the manuscript's evaluation-layer section.
- `data/datasets_sample/` is explicitly a smoke set (100/80 records). The full corpora are
  regenerated with the command above; they are not stored in git because of size.
- The proxy materials (31,530 posts, 4,834 weak-labelled rows) and all ablation statistics
  are already public under `supporting_information/`; `proxy_scripts/` only adds the
  runners that produced them.
